# DecimalChain Tokenization

Сервис для тех, кто помогает проектам запускать токены в DecimalChain и получает вознаграждение за участие.

## Страницы

| Путь | Для кого |
|------|----------|
| `/` | Понятное объяснение, как это работает |
| `/create` | Добавить токен (владелец + помощники + подтверждения) |
| `/cabinet` | Личный кабинет: проекты и доход |
| `/admin` | Админка: процент выплат и реестр |
| `/token/:symbol` | Открытая страница токена |

## Запуск

```bash
npm install
npm run dev
```

## Деплой

Статика на Vercel / Netlify / Render: `npm run build` → папка `dist`.
